# remindme

A timer plugin / extension for KDE KRunner. Examples:

- `remindme 5` = 5 minutes
- `rme 5:30` = 5 minutes and 30 seconds
- `rme 8 pasta is ready!` = 8 minutes with the message "pasta is ready!"
- `rme 0:20` = 20 seconds
- `rme 20s` = 20 seconds
- `rme 4h` = 4 hours
- `rme 4:15:30 plumber arrives` = 4 hours, 15 minutes, and 30 seconds with the message "plumber arrives"

Inspiration: <https://store.kde.org/p/1081014/>

Reference: <https://develop.kde.org/docs/>
